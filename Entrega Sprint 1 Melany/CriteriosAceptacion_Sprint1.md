# Criterios de Aceptación - Sprint 1 (Melany Bueso)

## HU-01: Iniciar sesión
* **CA-1:** Si la cuenta está activa y las credenciales son correctas, el sistema abre la pantalla permitida para su rol.
* **CA-2:** Si los datos son incorrectos, el acceso se rechaza.

## HU-02: Gestionar usuarios
* **CA-1:** El administrador completa los campos obligatorios y se crea una cuenta con login único.
* **CA-2:** Si el login ya existe, se muestra un error.

## HU-03: Asignar roles
* **CA-1:** El sistema guarda la asociación entre usuario y rol.
* **CA-2:** Si un cajero intenta realizar una acción administrativa, los permisos son denegados.
